# Test Analyzer AI Review Prompt

You are reviewing a Cypress test analysis report.

Use the generated report to explain:

1. What kinds of tests exist in the repository
2. How many tests there are
3. What product or technical areas they cover
4. What gaps or risks exist
5. How the test suite could be improved
6. What the next best automation improvements should be

Prioritise practical Quality Engineering recommendations.

Do not invent coverage that is not visible in the report.

If a coverage area is inferred from keywords rather than directly proven, state that clearly.

Focus on:

- maintainability
- scalability
- CI/CD readiness
- test data quality
- API contract risk
- negative test coverage
- flaky test prevention
- performance and token usage of the analysis approach
